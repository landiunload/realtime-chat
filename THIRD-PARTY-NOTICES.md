# Third-party dependencies

Срез проверен 27 августа 2026 года по восстановленному NuGet-графу и метаданным
пакетов. Коммерческих или proprietary-лицензий не найдено.

| Лицензия | Пакеты |
| --- | --- |
| MIT | `Microsoft.*`, `System.*`, SignalR JavaScript |
| Apache-2.0 | `Castle.Core`, `xunit.*` |
| BSD-3-Clause | `NSubstitute` |
| PostgreSQL | `Npgsql`, `Npgsql.EntityFrameworkCore.PostgreSQL`, PostgreSQL |

Точные версии NuGet находятся в двух `packages.lock.json`. Лицензии относятся
только к сторонним компонентам и не задают лицензию исходного кода этого репозитория.
